Specimen TW-01Aug 2026 —

Cognitive

  • A JavaScript browser extension captures AI-usage events (duration, frequency, context). A Python FastAPI ingestion service turns them into one structured format.
  • Celery + Redis run async event processing and model inference, covering tracking, ingestion, storage and analysis under high-concurrency writes.
  • User features built from raw logs (usage stats, time patterns, goal preferences) give an Ollama-hosted open-source LLM the context to turn goals into personalised daily plans.
Extension→FastAPI→Celery + Redis→Features→Ollama LLM

Specimen TW-02Sep 2026 —

TripSync

  • A cross-platform app where a group creates, edits and manages one shared trip itinerary.
  • Relational model for users, trips, members, preferences and activities, with foreign keys and permissions keeping concurrent edits consistent.
  • SQL aggregates members' preferences, and the Google Places and OpenAI APIs turn them into place recommendations and AI-drafted itineraries.
